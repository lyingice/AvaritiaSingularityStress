## 模型与槽位对应

- 主体 `models/block/blaze_cube_crafter/block.json`（datagen）：parent `create:block/mechanical_crafter/block`，槽 3/4/5/7/8/particle。
- 动态部件 `lid` / `arrow` / `belt_animated`（datagen）：parent 对应 Create 部件，槽 3 = `crafter_thingies`。
- 皮带框 `belt`（datagen）：parent `create:block/mechanical_crafter/belt`，槽 5 = `crafter_casing`。
- 齿轮 `cogwheel.json`（**手写**，复制 `crystal_matrix/cogwheel_shaftless.json` 的 Blockbench 几何，仅改 #1_2）：parent `create:block/large_wheels`，texture_size 32×32，#1_2 = `crafter_cogwheel`。不走 datagen，避免覆盖。
- 物品 `models/item/blaze_cube_crafter.json`（datagen）：parent `create:block/mechanical_crafter/item`，槽 3/4/5/7/8/9/particle。
- blockstate（datagen）：16 个 facing×pointing 变体共用主体模型。

## 连接纹理（CT）sprite shift

定义在 `init/client/ModSpriteShifts.java`，源/目标与上表一致：

- `BLAZE_CUBE_CRAFTER_FRONT`：OMNIDIRECTIONAL，`crafter_casing` → `crafter_casing_connected`。
- `BLAZE_CUBE_CRAFTER_SIDE`：VERTICAL，`crafter_side` → `crafter_side_connected`。
- `BLAZE_CUBE_CRAFTER_OTHERSIDE`：HORIZONTAL，`crafter_side` → `crafter_side_connected`。

CT 模型包装在 `ModClientEvents.onModifyBakingResult` 按注册 ID `blaze_cube_crafter` 匹配并排除 `inventory` 变体。

## 替换提示

- 只改贴图内容：直接覆盖同名 PNG，重新加载资源即可。
- 改文件名或槽位：需同步 `ModBlockStateProvider` / `ModModelProvider` / `ModSpriteShifts` 与手写齿轮模型，再重新 `runData`。
- 齿轮若想换成炽骨主题，可把 `crafter_cogwheel.png` 替换为本模组 `blaze_cube_cogwheel.png` 的内容（同为 32×32）。
