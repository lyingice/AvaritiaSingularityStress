## 0. 一句话定位

**把 Create 的旋转应力，变成无尽贪婪的中子态素产线。**

无尽贪婪原来的痛点是：中子态素靠"奇点压缩机"吃矿物、靠时间堆，越到后期越像挂机。
这个模组把整条产线搬进 Create 的动力体系：你不必再喂它矿物，只要有一张**产能富余**的应力网络，它就会自己把"富余的转速"压成材料。

给玩家的心智模型就三句话：

1. 我有一张**有空闲**的动力网；
2. 奇点压缩器把空闲压成 **SSU（奇点应力）**，沿传动链往下游流；
3. 下游机器看到足够的 SSU，就进入**奇点状态**，产量暴涨。

## 1. 核心机制：奇点应力（SSU）

### 1.1 为什么不是"第二种应力"

Create 的应力是一个不区分单位的 float 池，模组没法真的插一套"第二种应力"进去。所以 SSU 不是资源条，而是**每台奇点压缩器算出来的一个数值**，靠传动链的方向性往下传。

理解这一点，后面所有"为什么我的机器不发光"就都能自己推出来了。

### 1.2 产出：由**空闲应力**驱动

```
空闲应力 = 网络总产能 − 全网实际消耗      (不足 0 按 0 算)
单台产出 = max(0, 空闲应力 − 产能门槛) ÷ 压缩比
```

默认值：**产能门槛 1024 SU，压缩比 32 SU/SSU**。

举个直观的例子：

| 你的网络 | 空闲应力 | 产出 |
|---|---|---|
| 产能 800，消耗 0 | 800 | **0**（没过 1024 门槛） |
| 产能 8192，消耗 0 | 8192 | (8192−1024)/32 = **224 SSU** |
| 产能 8192，消耗 7000 | 1192 | (1192−1024)/32 = **5.25 SSU** |

**这是全模组最重要的设计意图**：它惩罚"满载"，奖励"过剩产能"。你的电站必须在带满所有机器之后还有富余，才能产出 SSU——所以后期要堆的不是"够用"，是"过量"。

### 1.3 传导：只走**子链**，不全网共享

SSU 不会在整张网络里平均分。每台机器沿自己的 `source` 指针**向上游回溯**，链路上每台运转中的奇点压缩器都把自己的产出贡献给它。

```
动力源 → 大齿轮 → 奇点压缩器 → 传动杆 → 收集器 A
                              ↘ 传动杆 → 压缩机 B
```

- 收集器 A、压缩机 B 都在这台压缩器的**输出侧**，都能看到它的 SSU；
- 如果某台机器是"从另一条支路接过来的"，它回溯不到压缩器，**一点 SSU 都看不到**。

> 教程要点：**"接在压缩器输出侧"是硬性要求**，不是"在同一个网络里"就行。这是玩家最容易踩的坑。

链路上有几台压缩器，产出就叠加。链路上有未加载的区块，回溯中断，视为看不到 SSU。

### 1.4 浓度与四级状态

每台机器单独算自己的浓度：

```
本机实际应力消耗(SU) = 该方块 SU/RPM × |当前转速|
需要 SSU           = 本机实际消耗 ÷ 压缩比(32)
奇点浓度           = 可见 SSU ÷ 需要 SSU      (截断在 0~100%)
```

**浓度满 100% 且位于压缩器输出侧 → 进入奇点状态**，再按转速升级：

| 状态 | 触发条件 | 效果 |
|---|---|---|
| 无（灰） | 浓度<100% 或不在输出侧 | 普通运转 |
| 奇点状态（青） | 浓度=100% | **产出周期减半**（2 倍产能），并解锁双倍/四倍判定 |
| 超激发态（金） | 奇点 + 转速过阈值 | 收集器：额外产量加成；压缩机：双倍/四倍概率生效 |
| 终极激发态（紫） | 仅极限档，≥256 RPM | 收集器：再 +1；压缩机：四倍概率生效 |

转速阈值不一样，**这是常被搞混的点**：

- **收集器**：>128 RPM 进入超激发（且只有致密/精英/极限档有加成，基础档永远不进超激发）
- **压缩机**：≥64 RPM 就进超激发
- **终极**：两者都要极限档 + ≥256 RPM

### 1.5 品控损耗与奇点稳定器

奇点压缩器不是白干的，它自己还要额外吃一笔损耗：

```
空闲比例 = 空闲应力 ÷ 总产能
品控损耗 = 8 + (32 − 8) × 空闲比例      (单位 SU/RPM)
压缩器自身占用 = 32 + 品控损耗           (单位 SU/RPM)
```

也就是说：网络越"闲"，损耗越高（8→32 浮动）。看着反直觉，其实是自平衡——闲得越多说明你产能越大，那就多收点税。

**奇点稳定器**把它下游所有压缩器的品控损耗直接清零，占用回到纯 32 SU/RPM。一台稳定器管一条支路，多台各管各的，不叠加、不共享。

> 教程要点：稳定器要放在**压缩器的上链路**（压缩器的 source 链能回溯到它），不是随便放网络里就行。

### 1.6 转速的唯一作用：缩短周期

这条一定要讲清楚，否则玩家会以为转速还有别的加成：

```
周期缩短倍率 = 1 + 7 × (clamp(转速, 16, 256) − 16) ÷ 240
实际周期     = 基准周期 ÷ 倍率
```

- 16 RPM → 1×（基准周期）
- 256 RPM → 8×（周期缩到 1/8）
- **低于 16 RPM 完全不产出**；超过 256 RPM 不再加速

## 4. 逐台详解

### 4.1 奇点压缩器（Singularity Compressor）

**它是 Create 转速控制器的改造版**，传动逻辑完全继承：

- 上方需要 **大齿轮** 驱动（不是普通传动杆输入面）；
- 输出侧向下游网络注入动力；
- 它不拆网，输入输出仍属同一张网络。

**它额外做的两件事**：把空闲应力压成 SSU、按空闲比例收品控损耗。

**护目镜读数**（这是全模组的信息中心）：

```
动力学状态：
应力影响：
  4096 su 当前速度值
奇点应力：
奇点应力影响：
  128 ssu 当前速度值
奇点浓度：100.00%
状态：奇点状态（超激发态）
```

- 产出为 0 时会明确提示"空闲应力未达门槛(1024 su)"；
- 品控损耗被抑制时显示绿色的"稳定器：品控损耗已抑制"；
- 停转时显示"待机：未运转"。

### 4.2 奇点稳定器（Singularity Stabilizer）

轴式动能方块，**自身不耗应力**。放进网络、位于压缩器上链路即生效。
效果：该压缩器品控损耗归零（32 + 0），护目镜上立刻能看到那行绿字。
Jade 上会常显一行"额外损耗抑制中"。

### 4.3 动能中子态素收集器（四档）

| 档位 | 应力 | 16 RPM 基准周期 | 产物 | 超激发加成 |
|---|---|---|---|---|
| 基础 | 32 SU/RPM | 320 秒 | 中子尘埃 | — |
| 致密 | 64 SU/RPM | 280 秒 | 中子颗粒 | +1 |
| 精英 | 128 SU/RPM | 240 秒 | 中子锭 | +2 |
| 极限 | 256 SU/RPM | 200 秒 | 中子块 | +3（≥256 RPM 终极态再 +1） |

- 奇点状态下基准周期先**减半**，再套转速倍率；
- 单格输出槽，满了会挂起进度（不会丢失）；
- 产物走的是 `c:dust/neutronium` 这类通用标签，所以和 Re-Avaritia 的物品是同一套。

**满速算例（极限档 + 奇点 + 256 RPM）**：
基准 200 秒 → 奇点减半 100 秒 → 256 RPM 除 8 → 12.5 秒一个，且每次 5 个（1+3+1）。
也就是 **≈24 个中子块/分钟**，一台机器。

### 4.4 动能中子态素压缩机（四档）

**关键区别**：四档**能耗完全一样**（都是 32 SU/RPM），差别全在效能。所以档位不是"更强"，是"更省料/更容易翻倍"。

配方直接复用无尽贪婪的 `avaritia:compressor_recipe`，产物和原版压缩机一模一样。

| 档位 | 原料减免 @64/128/256 RPM | 双倍概率 | 四倍概率 |
|---|---|---|---|
| 基础 | 5% / 10% / 20% | — | — |
| 致密 | 10% / 15% / 30% | 3% / 6% / 9% | — |
| 精英 | 20% / 25% / 45% | 9% / 18% / 27% | — |
| 极限 | 40% / 55% / 65% | **100%** | 12% / 18% / 27% |

- 原料减免是**按 RPM 档位阶梯**给的，不是线性；
- 双倍/四倍**必须处于奇点状态**才会触发（普通状态永远 1 倍）；
- 基准周期 320 tick（16 秒），奇点态减半 160 tick；
- GUI 里能看到"材料收集进度"和"合成进度"两条。

**极限档满配算例**：奇点 + 256 RPM → 周期 160/8 = 20 tick（1 秒），双倍 100%、四倍 27%。
期望产出 ≈ 1 + 1.0 + 2×0.27 = **2.54 倍/次**，原料还只花 35%。

### 4.5 终焉动力合成器（Extreme Mechanical Crafter）

对 Create 动力合成器的**完整独立复刻**（不是继承），所以不受原版对"机械合成器"的硬编码限制。

- **网格上限 9×9 = 81 台**，每台只存 1 个物品，空槽用 `create:crafter_slot_cover` 盖板；
- **应力 8 SU/RPM/台**（原版是 2），所以 5×5=25 台、32 RPM 就是 6400 SU，很吃产能；
- 相邻**不会自动连网**，必须用**扳手点非正面**把相邻方块并进同一连接组；
- 整组共享一份库存，对漏斗/机械臂暴露，可以按配方顺序投料；
- 合成速度随转速：`倒计时速度 = clamp(转速, 4, 250)`，32 RPM 约 3.1 秒，250 RPM 以上约 0.4 秒。

**配方匹配优先级**（这个顺序很重要）：

```
链上有终焉锻造器？
├─ 是：① 本模组 extreme_kinetic_smithing
│      ② 无尽贪婪 extreme_smithing
│      ③ 本模组 extreme_kinetic_crafting
│      ④ 无尽贪婪分级配方（幽匿/下界/末地/终焉）
└─ 否：③ 本模组 extreme_kinetic_crafting
       ④ 无尽贪婪分级配方
```

**它不匹配**原版工作台配方，也**不匹配** `create:mechanical_crafting`。这点必须讲，否则玩家会拿普通配方来试。

> 说明：本版本**不自带** `extreme_kinetic_crafting` / `extreme_kinetic_smithing` 的示例配方，这两个类型是给整合包作者/数据包用的；开箱即用时靠第 ④ 条回落到无尽贪婪自己的配方。

### 4.6 终焉锻造器（Extreme Smithing Crafter）

行为、应力、库存、状态机全部继承终焉动力合成器。唯一差别：

> 只要它出现在合成链里，整条链就优先尝试 **5 格锻造配方**（模板 + 基座 + 3 添加物），模板和基座位置**自动搜索**，玩家不用记摆位。

典型布局：中心 1 台锻造器 + 四向 4 台合成器 = 5 格。

### 4.7 无线物品传输漏斗（Wireless Item Funnel）

黄铜漏斗外观，**一个方块两种角色**，用扳手循环 `EXTRACTING` 属性切换：

- **抽取端**：每 5 tick 从朝向的容器抽 **1 个**物品，放进自己的缓存（受过滤槽约束，缓存只装一种物品）；
- **接收端**：从唯一对端的缓存取 1 个，注入自己朝向的容器。

限制与规则：

- 配对距离 **64 格**（可配置），必须同维度、**一对一**（0 个或 ≥2 个同频对端都不工作）；
- 红石通电 → 整机停止；
- 刻意**没有**传送带退化行为（不会变成带上漏斗）。

### 4.8 无线应力传输器（Sender / Receiver）

在两个**彼此独立**的应力网络之间隔空传动力——相当于一根"无线传动轴"。

- **输出端**：每 5 tick 从源网抽 `min(源网空闲应力, 送出上限)`，推给配对接收端；
- **接收端**：把收到的量当作**本网新增产能**，并**沿用源网的转速**；收到 0 → 本网直接停转；
- **看门狗 20 tick**：输出端一旦消失/拆掉/区块卸载，接收端 20 tick 后自动断流（不会永久白送动力）；
- 送出上限、接收上限、优先级可分别配置（0 或负数 = 不限）；
- 只有**背面**这一面能接轴/齿轮；
- 只有输出端需要"源网有空闲应力"。

> 教程场景：跨山、跨海、地底电站给地面工厂供电，一根"无线轴"搞定。

## 6. 配置项（给整合包作者）

```
# 服务端 config
compressionRatio = 32      # 多少 SU 压成 1 SSU
capacityGate     = 1024    # 空闲应力低于此值不产 SSU
qualityLossMin   = 8       # 空闲比例 0% 时的品控损耗
qualityLossMax   = 32      # 空闲比例 100% 时的品控损耗
b6StressPerRpm   = 32      # 压缩器基础占用
ssuToSuRatio     = 1.0     # 护目镜显示的 SSU 等效倍率

# 通用 config
itemFunnelRange   = 64     # 无线漏斗配对距离
stressBridgeRange = 64     # 无线应力传输器配对距离
maxFrequency      = 9999   # 频率上限
```

想更"肝"就调高 `capacityGate` 或 `compressionRatio`；想更宽松就调低。

## 7. 玩家常见误区（录制时建议逐条演示）

1. **"我接了网络为什么不产 SSU？"** —— 空闲应力没过 1024 门槛。加产能，或者减负载。
2. **"我机器在同一个网络里，为什么浓度是 0？"** —— 不在压缩器**输出侧**（source 链回溯不到压缩器）。
3. **"浓度 99% 卡住不动"** —— 差一点点。SSU 是按整台机器的消耗算的，多上一台压缩器或降转速。
4. **"压缩器自己怎么也在吃我 8~32 SU？"** —— 那是品控损耗，上稳定器清零。
5. **"稳定器放了没用"** —— 放的位置不在压缩器上链路。
6. **"转速拉到 512 是不是更快？"** —— 不会，256 RPM 封顶。
7. **"双倍产出怎么从来不出？"** —— 必须奇点状态 + ≥64 RPM，且档位越高概率越高（基础档没有）。
8. **"合成器不吃我的配方"** —— 它不匹配原版工作台配方，只认无尽贪婪系。
9. **"合成器摆在一起就能用了吧？"** —— 必须扳手点非正面并组，否则各算各的。
10. **"无线漏斗连不上"** —— 检查：同维度、64 格内、频率一致、私有/公用一致、一对一（不能同时有两个对端）。
