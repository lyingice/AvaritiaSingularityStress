## 替换提示

- 只改贴图内容：覆盖同名 PNG，重新加载资源（渲染代码改动需重启客户端）。
- 钻头改文件名/槽位：同步 `extreme_drill/head.json`、`block.json`、`item/extreme_drill.json`。
- 水车改贴图：覆盖 `extreme_water_wheel/` 下同名 PNG（外壳 gearbox/漏斗框 + 轮体 metal/axis/oak 等）。
