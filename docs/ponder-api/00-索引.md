## 2. 类清单

「外部可用」一列含义：

- ✅ **外部可用** — 这是 Ponder 设计给第三方 mod 的 API，可以直接调用/实现。
- ⚠️ **可用但属实现细节** — public 且能调，但不是稳定契约；升级版本可能变，能不用就不用。
- ❌ **内部实现** — 只供 Ponder 自身使用；调了大概率没有效果或直接崩，**不要碰**。

## 3. 关键事实（逐条核实，附证据）

| # | 事实 | 证据来源 |
| --- | --- | --- |
| 1 | `SceneBuildingUtil` **没有** `SELECT`/`GRID`/`VECTOR` 常量字段，只有 `select()`/`vector()`/`grid()` 三个方法 | `javap -public` 无任何字段输出 |
| 2 | 剧情资源路径固定为 `assets/<namespace>/ponder/<path>.nbt` | `PonderSceneRegistry.loadSchematic` 常量池字符串 `ponder/\u0001.nbt` |
| 3 | `addStoryBoard(组件, "my_scene", board)` 里传的字符串是**纯 path**，命名空间取插件的 `getModId()` | `DefaultPonderSceneRegistrationHelper.asLocation` → `ResourceLocation.fromNamespaceAndPath(namespace, path)` |
| 4 | 场景标题语言键 = `<ns>.ponder.<scene>.header` | `PonderScene.TITLE_KEY` ConstantValue = `header`；`PonderLocalization` 常量 `\u0001.ponder.\u0001.\u0001` |
| 5 | 共享文本键 = `<ns>.ponder.shared.<key>` | `PonderLocalization` 常量 `\u0001.ponder.shared.\u0001` |
| 6 | 标签名/描述键 = `<ns>.ponder.tag.<tag>` / `<ns>.ponder.tag.<tag>.description` | `PonderLocalization` 常量 |
| 7 | `LANG_PREFIX = "ponder."`，`UI_PREFIX = "ui."` | `PonderLocalization` ConstantValue |
| 8 | `showSection` / `hideSection` 的淡入淡出时长硬编码为 **15 tick** | `PonderSceneBuilder$PonderWorldInstructions` 字节码 `bipush 15` |

| 11 | 注册阶段结束后再加剧情会抛错：`"Registration Phase has already ended!"` | `PonderSceneRegistry` 常量池 |
| 12 | `PonderIndex.reload()` = 清空 shared/场景/标签 → `registerAll()`（先 registerScenes 再 registerTags）→ `gatherSharedText()` | `PonderIndex` 字节码 |

## 4. 最小可用骨架（签名全部来自 javap，未加任何未验证逻辑）

~~~java
// 1) 实现插件：唯一必须实现的方法是 getModId()
public class MyPonderPlugin implements PonderPlugin {
    @Override
    public String getModId() { return "mymod"; }

    @Override
    public void registerScenes(PonderSceneRegistrationHelper<ResourceLocation> helper) {
        helper.addStoryBoard(
            ResourceLocation.fromNamespaceAndPath("mymod", "my_block"), // 组件 id
            "my_first_scene",                                          // 纯 path，对应 assets/mymod/ponder/my_first_scene.nbt
            (scene, util) -> {                                         // PonderStoryBoard 是函数式接口
                scene.title("my_first_scene", "我的第一段思索");        // (场景 key, 标题)
                scene.configureBasePlate(0, 0, 5);
                scene.showBasePlate();
                scene.idle(20);
                scene.overlay().showText(60).text("看这里").pointAt(util.vector().centerOf(2, 1, 2));
            }
        );
    }

    @Override
    public void registerTags(PonderTagRegistrationHelper<ResourceLocation> helper) {
        helper.registerTag("mymod/my_tag")   // TagBuilder
              .title("我的标签")
              .description("说明")
              .item(MyItems.MY_ITEM.get())
              .addToIndex()
              .register();                   // ← 不调 register() 不生效
    }
}

// 2) 把插件交给 Ponder（具体时机见 30-registration.md 的「注册时机」一节）
PonderIndex.addPlugin(new MyPonderPlugin());
~~~

> 上面 `addStoryBoard` 的 3 参数重载、`registerTag(String)`、`TagBuilder` 链式方法、
> `scene.title/configureBasePlate/showBasePlate/idle/overlay().showText` 全部有 javap 证据。
> **`PonderIndex.addPlugin` 的调用时机属于生命周期问题**：字节码只能证明它把插件排进静态列表，
> 不能证明「必须在哪个事件里调」。该点标注为**未验证**，见 [30-registration.md](30-registration.md#注册时机)。
