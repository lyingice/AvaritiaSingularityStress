## 2. 注册链路：4 级，缺一不可

```text
@Mod(dist=CLIENT) CreateClient            ① 类级限定：只在客户端加载
  └─ modEventBus.addListener(::clientInit)  ② 时机 = FMLClientSetupEvent
       └─ PonderIndex.addPlugin(new CreatePonderPlugin())   ③ 注册插件
            └─ CreatePonderPlugin.registerScenes(helper)     ④ 插件回调里注册
                 ├─ AllCreatePonderScenes.register(helper)
                 └─ AllCreatePonderTags.register(helper)
```

### 2.1 第 ① 级：类级 `dist = Dist.CLIENT`

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/CreateClient.java:51-52
@Mod(value = Create.ID, dist = Dist.CLIENT)
public class CreateClient {
```

配套 import（证明 `Dist` 来自 NeoForge 而非 Forge）：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/CreateClient.java:45-49
import net.neoforged.api.distmarker.Dist;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.fml.common.Mod;
import net.neoforged.fml.event.lifecycle.FMLClientSetupEvent;
```

> **什么时候必须这样写**：只要注册代码里出现任何 `net.minecraft.client.*`（Ponder 必然如此），入口类就必须钉在 `Dist.CLIENT`。否则专用服务器启动时 `NoClassDefFoundError`。

## 5. 场景注册总表 `AllCreatePonderScenes`

入口方法只有 3 行：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/AllCreatePonderScenes.java:69-73
public class AllCreatePonderScenes {

	public static void register(PonderSceneRegistrationHelper<ResourceLocation> helper) {
		PonderSceneRegistrationHelper<ItemProviderEntry<?, ?>> HELPER = helper.withKeyFunction(RegistryEntry::getId);

```

要点：
1. `helper` 泛型是 `PonderSceneRegistrationHelper<ResourceLocation>`；
2. 立刻 `withKeyFunction(RegistryEntry::getId)` **换成 registrate 的 `RegistryEntry`**，于是后面能直接写 `AllBlocks.SHAFT`（不用 `.get()`）；
3. `AllItems.X`/`AllBlocks.X` 都是 `ItemProviderEntry`，所以 72 行换成 `ItemProviderEntry<?, ?>` 后两边通吃。

### 5.1 `addStoryBoard` 两种写法

**单个组件挂一个场景**（`HELPER.addStoryBoard(组件, "场景id", 方法引用, 标签...)`）：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/AllCreatePonderScenes.java:102-103
		HELPER.addStoryBoard(AllBlocks.CLUTCH, "clutch", KineticsScenes::clutch, AllCreatePonderTags.KINETIC_RELAYS);
		HELPER.addStoryBoard(AllBlocks.GEARSHIFT, "gearshift", KineticsScenes::gearshift, AllCreatePonderTags.KINETIC_RELAYS);
```

**多组件共享、链式批量挂**（`forComponents(...)` 返回 `MultiSceneBuilder`）：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/AllCreatePonderScenes.java:79-82
		HELPER.forComponents(AllBlocks.COGWHEEL)
			.addStoryBoard("cog/small", KineticsScenes::cogAsRelay, AllCreatePonderTags.KINETIC_RELAYS)
			.addStoryBoard("cog/speedup", KineticsScenes::cogsSpeedUp)
			.addStoryBoard("cog/encasing", KineticsScenes::cogwheelsCanBeEncased);
```

### 5.2 场景 id 的真实形态

- 允许 `/` 分层：`"shaft/relay"`、`"belt/connect"`、`"mechanical_press/compacting"`、`"high_logistics/stock_link"`
- 允许不分层：`"gearbox"`、`"clutch"`、`"shafts"`
- 这个 id 决定 **`.nbt` 文件路径**；**不决定 lang key**（最容易踩的坑，见 §7）

一一对应的实证：`"belt/connect"` ↔ `assets/create/ponder/belt/connect.nbt`。

### 5.3 值得学的"批量"写法

列车轨道有 16 种材质，Create 用 `stream().map(...).toArray(...)` 造临时 `BlockEntry` 数组后一次性注册：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/AllCreatePonderScenes.java:391-402
		HELPER.forComponents(TrackMaterial.allBlocks()
				.stream()
				.map((trackSupplier) -> new BlockEntry<TrackBlock>(
					// note: these blocks probably WON'T be in the Create Registrate, but a simple
					// code trace reveals the Entry's registrate isn't used
					Create.registrate(),
					DeferredHolder.create(Registries.BLOCK, BuiltInRegistries.BLOCK.getKey(trackSupplier.get()))
				))
				.toArray(BlockEntry[]::new))
			.addStoryBoard("train_track/placement", TrackScenes::placement)
			.addStoryBoard("train_track/portal", TrackScenes::portal)
			.addStoryBoard("train_track/chunks", TrackScenes::chunks);
```

> **什么时候用**：同一套场景要挂到大量「动态生成」的组件上（染色变体、材质变体、枚举组合）。手写 `.add(...)` 会爆炸。

### 6.2 标签注册 + 加进索引

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/AllCreatePonderTags.java:47-59
	public static void register(PonderTagRegistrationHelper<ResourceLocation> helper) {

		PonderTagRegistrationHelper<RegistryEntry<?, ?>> HELPER = helper.withKeyFunction(RegistryEntry::getId);

		PonderTagRegistrationHelper<ItemLike> itemHelper = helper.withKeyFunction(
				RegisteredObjectsHelper::getKeyOrThrow);

		helper.registerTag(KINETIC_RELAYS)
				.addToIndex()
				.item(AllBlocks.COGWHEEL.get(), true, false)
				.title("Kinetic Blocks")
				.description("Components which help relaying Rotational Force elsewhere")
				.register();
```

## 7. lang key 的硬规则（最该背下来的一节）

### 7.1 结论：key 由 `scene.title(第一参数, 默认英文)` 决定，**不是**由场景 id 决定

`AllCreatePonderScenes.java:76-77` 注册的场景 id 是 `"shaft/encasing"`，但生成出来的 key 是 `create.ponder.shaft_casing.header`——因为场景代码写的是：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/KineticsScenes.java:75-78
	public static void shaftsCanBeEncased(SceneBuilder builder, SceneBuildingUtil util) {
		CreateSceneBuilder scene = new CreateSceneBuilder(builder);
		scene.title("shaft_casing", "Encasing Shafts");
		scene.configureBasePlate(0, 0, 5);
```

同理 `"belt/connect"`（`AllCreatePonderScenes.java:90`）→ key `create.ponder.belt_connector.*`，因为书写的是 `scene.title("belt_connector", ...)`。

### 7.2 反编译实证的拼接格式

```text
4: makeConcatWithConstants   recipe = \u0001.ponder.\u0001.\u0001

```

`PonderScene.TITLE_KEY` 常量值：


于是四种 key 形态被唯一确定（样例全部取自 `allapis/Create-mc1.21.1-dev/src/generated/resources/assets/create/lang/en_us.json`）：

| 用途 | key 形态 | 真实样例 |
|---|---|---|
| 场景标题 | `<namespace>.ponder.<title第一参数>.header` | `create.ponder.shaft_casing.header` = `"Encasing Shafts"` |
| 场景第 N 句 | `<namespace>.ponder.<title第一参数>.text_N` | `create.ponder.shaft_casing.text_1` = `"Brass or Andesite Casing can be used to decorate Shafts"` |
| 标签名 | `<namespace>.ponder.tag.<tag路径>` | `create.ponder.tag.kinetic_relays` = `"Kinetic Blocks"` |
| 标签描述 | `<namespace>.ponder.tag.<tag路径>.description` | `create.ponder.tag.kinetic_relays.description` = `"Components which help relaying Rotational Force elsewhere"` |
| 共享文本 | `<namespace>.ponder.shared.<key>` | `create.ponder.shared.movement_anchors` = `"With the help of Super Glue, larger structures can be moved."` |
| 模组名 | `<namespace>.ponder.mod_name` | `create.ponder.mod_name` = `"Create"` |

> **是 `.header`，不是 `.title`。** 这是最常被写错的一处。

共享文本格式还能用 Ponder 库自己的 lang 反向验证：jar 内 `assets/ponder/lang/en_us.json` 有 `"ponder.ponder.shared.sneak_and":"Sneak +"`（namespace=`ponder`、key=`sneak_and`），恰好符合 `<ns>.ponder.shared.<key>`。

### 7.3 `text_N` 的编号规则

`PonderScene` 维护 `private int textIndex;`，`registerText(...)` 每调用一次就用当前 `textIndex` 拼 key 并自增。反编译片段（`javap -c`）：

```text
public java.util.function.Supplier<java.lang.String> registerText(java.lang.String);
   4: invokedynamic #792  // makeConcatWithConstants:(I)Ljava/lang/String;   ← "text_" + index
   ...
  20: invokevirtual #796  // PonderLocalization.registerSpecific(ResourceLocation, String, String)
   ...
  33: getfield      #113  // Field textIndex
  36: iconst_1
  37: iadd
  38: putfield      #113  // textIndex = textIndex + 1
```

所以 `text_1`/`text_2`… 按 `showText(...)` / `showOutlineWithText(...)` 的出现顺序自动编号。真实样本（`analog_lever` 恰好 3 句）：

```json
  "create.ponder.analog_lever.header": "Controlling signals using the Analog Lever",
  "create.ponder.analog_lever.text_1": "Analog Levers make for a compact and precise source of redstone power",
  "create.ponder.analog_lever.text_2": "Right-click to increase its analog power output",
  "create.ponder.analog_lever.text_3": "Right-click while Sneaking to decrease the power output again",
```

> 补充：Create 里 `belt_connector` 有 `text_1`…`text_6`，`basin` 有 `text_1`…`text_9`，编号连续无跳号，可交叉验证上述规则。

### 7.4 写手册时必须告诉用户的 3 件事

1. **不要凭感觉手写 key**。先 `scene.title("my_key", "English default")`，跑一次 `runData`，看生成的 `en_us.json`，再照搬 key 翻中文。
2. **场景 id 与 lang key 可以不同名**，但强烈建议同名——Create 里所有不同名的（`shaft/encasing` vs `shaft_casing`）都会让后来者困惑。
3. `text_N` 会**因插入/删除一句而整体重排**。改故事线后中文必须重新对齐。

## 9. 索引排除（避免染色变体刷屏）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/foundation/ponder/CreatePonderPlugin.java:54-59
	@Override
	public void indexExclusions(IndexExclusionHelper helper) {
		helper.excludeBlockVariants(ValveHandleBlock.class, AllBlocks.COPPER_VALVE_HANDLE.get());
		helper.excludeBlockVariants(PostboxBlock.class, AllBlocks.PACKAGE_POSTBOXES.get(DyeColor.WHITE).get());
		helper.excludeBlockVariants(TableClothBlock.class, AllBlocks.TABLE_CLOTHS.get(DyeColor.WHITE).get());
	}
```

签名：

```text
public interface net.createmod.ponder.api.registration.IndexExclusionHelper {
  public abstract IndexExclusionHelper exclude(net.minecraft.world.level.ItemLike);
  public abstract IndexExclusionHelper excludeItemVariants(Class<? extends Item>, Item);
  public abstract IndexExclusionHelper excludeBlockVariants(Class<? extends Block>, Block);
  public abstract IndexExclusionHelper exclude(java.util.function.Predicate<net.minecraft.world.level.ItemLike>);
}
```

> **什么时候用**：方块是 `DyeColor` 十六色变体时，索引会出现 16 个雷同图标。用 `excludeBlockVariants(MyBlock.class, MY_BLOCK.get())` 留一个代表即可。

## 10. datagen 时的第二次注册（隐藏大坑）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/data/CreateDatagen.java:102-107
	private static void providePonderLang(BiConsumer<String, String> consumer) {
		// Register this since FMLClientSetupEvent does not run during datagen
		PonderIndex.addPlugin(new CreatePonderPlugin());

		PonderIndex.getLangAccess().provideLang(Create.ID, consumer);
	}
```

原文注释直接给出原因：**`FMLClientSetupEvent` 在 datagen 时不运行**。所以生成 `en_us.json` 时必须**手动再 `addPlugin` 一次**，否则 `provideLang` 拿到空索引，生成的 lang 里一条 ponder key 都没有——**而且不报错**。

## 12. 抄作业顺序

1. `build.gradle` 加 `implementation("net.createmod.ponder:ponder-neoforge:<ver>+mc1.21.1")`
2. 建 `MyPonderPlugin implements PonderPlugin`，`getModId()` 返回你的 modid
3. 建 `@Mod(value = MY_ID, dist = Dist.CLIENT)` 客户端入口类，在 `FMLClientSetupEvent` 里 `PonderIndex.addPlugin(new MyPonderPlugin())`
4. `registerScenes` 里 `helper.withKeyFunction(...)` + `addStoryBoard(...)`
5. 准备 `assets/<modid>/ponder/<scene id>.nbt`
6. 跑 `runData`，把生成的 `en_us.json` 里 `<modid>.ponder.*` 搬到 `zh_cn.json` 翻译
7. `/ponder reload` → `/ponder index` 验收
