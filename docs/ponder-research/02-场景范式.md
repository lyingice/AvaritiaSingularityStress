## 0. 场景方法的标准签名（所有范式的共同外壳）

Create 的每个场景都是一个 `public static void XXX(SceneBuilder builder, SceneBuildingUtil util)`。方法体第一行永远是把自己的 builder 升格成 Create 版：

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/KineticsScenes.java:41-42
	public static void shaftAsRelay(SceneBuilder builder, SceneBuildingUtil util) {
		CreateSceneBuilder scene = new CreateSceneBuilder(builder);
```

`util` 是框架注入的 `SceneBuildingUtil`，权威签名只有 3 个方法（javap 实证）：

```text
public interface net.createmod.ponder.api.scene.SceneBuildingUtil {
  public abstract SelectionUtil select();    // util.select()  → 选方块
  public abstract VectorUtil    vector();    // util.vector()  → 取坐标点
  public abstract PositionUtil  grid();      // util.grid()    → 取 BlockPos
}
```

**为什么非要包一层 `CreateSceneBuilder`**：它多了 `setKineticSpeed / rotateBearing / movePulley / instructArm / superGlue …` 等 Create 专属指令（全文见 `foundation/ponder/CreateSceneBuilder.java`）。你的 mod 不需要这层，直接用 `builder` 即可。

# 范式 1 · 最小可用 storyboard（世界 + 标题 + 一句话）

**什么时候用**：新手上路，先验证「注册链路通不通、nbt 有没有被读到」。这是第一个该跑通的场景。

### 1.1 Create 自己的模板文件（原文，全文件 20 行）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/TemplateScenes.java:9-20
public class TemplateScenes {

	public static void templateMethod(SceneBuilder builder, SceneBuildingUtil util) {
		CreateSceneBuilder scene = new CreateSceneBuilder(builder);
		scene.title("", "");
		scene.configureBasePlate(0, 0, 5);
		scene.world().showSection(util.select().layer(0), Direction.UP);
		scene.idle(5);
		scene.world().showSection(util.select().layersFrom(1), Direction.DOWN);
	}

}
```

> `TemplateScenes.java` 在 Create 里**没有被注册**（`AllCreatePonderScenes` 里 0 命中）——它纯粹是一份留给人复制的模板。这本身就是最好的"最小范式"。

### 1.2 真正能跑的极简场景

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/KineticsScenes.java:41-73
	public static void shaftAsRelay(SceneBuilder builder, SceneBuildingUtil util) {
		CreateSceneBuilder scene = new CreateSceneBuilder(builder);
		scene.title("shaft", "Relaying rotational force using Shafts");
		scene.configureBasePlate(0, 0, 5);
		scene.world().showSection(util.select().layer(0), Direction.UP);

		BlockPos gaugePos = util.grid().at(0, 1, 2);
		Selection gauge = util.select().position(gaugePos);
		scene.world().showSection(gauge, Direction.UP);
		scene.world().setKineticSpeed(gauge, 0);

		scene.idle(5);
		scene.world().showSection(util.select().position(5, 1, 2), Direction.DOWN);
		scene.idle(10);

		for (int i = 4; i >= 1; i--) {
			if (i == 2)
				scene.rotateCameraY(70);
			scene.idle(5);
			scene.world().showSection(util.select().position(i, 1, 2), Direction.DOWN);
		}

		scene.world().setKineticSpeed(gauge, 64);
		scene.effects().indicateSuccess(gaugePos);
		scene.idle(10);
		scene.overlay().showText(1000)
			.placeNearTarget()
			.text("Shafts will relay rotation in a straight line.")
			.pointAt(util.vector().of(3, 1.5, 2.5));

		scene.idle(20);
		scene.markAsFinished();
	}
```

**要点**

| 行 | 写法 | 含义 |
|---|---|---|
| 43 | `scene.title("shaft", "…")` | 第一参数是 **lang key 后缀**（不是场景 id！），第二参数是英文默认值 → 生成 `create.ponder.shaft.header` |
| 44 | `configureBasePlate(0, 0, 5)` | 底板：偏移 X=0、偏移 Z=0、边长 5 格 |
| 45 | `showSection(util.select().layer(0), Direction.UP)` | 先显示第 0 层（地基）。第二个参数是**淡入方向**（从哪个面冒出来） |
| 52-54 | `idle(5)` → `showSection(...)` → `idle(10)` | 节奏：动作之间必须留 idle，否则观众看不清 |
| 66-69 | `showText(1000)` + `.text(...)` | 1000 = 显示时长（tick），这里故意给 1000 表示"一直挂到场景结束" |
| 71-72 | `idle(20)` → `markAsFinished()` | **收尾必写**，否则进度条不会走完 |

### 2.2 `addLazyKeyframe()`：先做循环铺垫，再插关键帧

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/DetectorScenes.java:231-245
		for (int i = 0; i < 5; i++) {
			scene.world().createItemOnBelt(util.grid().at(3, 0, 0), Direction.NORTH, ironIngot);
			scene.idle(10);
			scene.world().removeItemsFromBelt(util.grid().at(3, 0, 2));
			scene.world().flapFunnel(util.grid().at(3, 1, 2), false);

			if (i % 2 == 1)
				scene.world().cycleBlockProperty(switchPos, ThresholdSwitchBlock.LEVEL);
		}

		scene.addLazyKeyframe();
		scene.world().createItemOnBelt(util.grid().at(3, 0, 0), Direction.NORTH, ironIngot);
		scene.world().removeItemsFromBelt(util.grid().at(3, 0, 2));
		scene.world().multiplyKineticSpeed(util.select().everywhere(), 1 / 8f);
		scene.idle(10);
```

> 关键：`addLazyKeyframe()` 用的是**当前时刻**但当它被读取时才生效（lazy）。Create 在"循环演完一轮、准备进入下一段解释"时插一帧，避免关键帧落在动画中间。

**API 对照（javap）**

```text
public interface net.createmod.ponder.api.scene.SceneBuilder {
  void title(java.lang.String, java.lang.String);
  void idle(int);
  void idleSeconds(int);
  void addKeyframe();
  void addLazyKeyframe();
  void markAsFinished();
  void setNextUpEnabled(boolean);
```

| 方法 | 单位 | 什么时候用 |
|---|---|---|
| `idle(n)` | tick（20/s） | 绝大多数情况 |
| `idleSeconds(n)` | 秒 | 只想表达"停 2 秒"时更直观 |
| `addKeyframe()` | — | 想让观众能"后退到这一步" |
| `addLazyKeyframe()` | — | 循环/批量动作之后补一个关键帧 |
| `setNextUpEnabled(true)` | — | 场景末尾显示"Up Next: …"（Create 无调用点，**未验证**具体观感） |

# 范式 4 · 显示/隐藏独立区块（showIndependentSection / hideSection / showSectionAndMerge / makeSectionIndependent）

**什么时候用**：想让某块结构**自己动**（旋转、平移、消失）——只要它要独立运动，就必须先 `showIndependentSection` 拿到 `ElementLink<WorldSectionElement>`。只想"出现/消失"而不独立动，用普通 `showSection`/`hideSection`。

### 4.1 WorldInstructions 的相关签名（javap 实证）

```text
ElementLink<WorldSectionElement> showIndependentSection(Selection, Direction);
ElementLink<WorldSectionElement> showIndependentSectionImmediately(Selection);
ElementLink<WorldSectionElement> makeSectionIndependent(Selection);
void hideSection(Selection, Direction);
void hideIndependentSection(ElementLink<WorldSectionElement>, Direction);
void glueBlockOnto(net.minecraft.core.BlockPos, Direction, ElementLink<WorldSectionElement>);
```

### 4.2 先独立、再用循环"缝"上去（风车的真实写法）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/BearingScenes.java:62-90
		ElementLink<WorldSectionElement> structure =
			scene.world().showIndependentSection(util.select().position(anchorPos), Direction.SOUTH);
		scene.idle(10);
		for (Direction d : Iterate.directions)
			if (d.getAxis() != Axis.Z)
				scene.world().showSectionAndMerge(util.select().fromTo(anchorPos.relative(d, 1), anchorPos.relative(d, 2)),
												  d.getOpposite(), structure);
		scene.idle(10);

		scene.world().showSectionAndMerge(util.select().fromTo(anchorPos.above()
			.east(),
															   anchorPos.above(3)
				.east()),
										  Direction.WEST, structure);
		scene.world().showSectionAndMerge(util.select().fromTo(anchorPos.below()
			.west(),
															   anchorPos.below(3)
				.west()),
										  Direction.EAST, structure);
		scene.world().showSectionAndMerge(util.select().fromTo(anchorPos.east()
			.below(),
															   anchorPos.east(3)
				.below()),
										  Direction.UP, structure);
		scene.world().showSectionAndMerge(util.select().fromTo(anchorPos.west()
			.above(),
															   anchorPos.west(3)
				.above()),
										  Direction.DOWN, structure);
```

要点：
- 62-63 行：先只让**锚点**独立显示；
- 65-68 行：其余方向用 `showSectionAndMerge(selection, 朝向, structure)` **合并进同一个 ElementLink**——这就是"看起来是一整台风车"的原因；
- 合并的第二个参数是**淡入方向**，要和几何朝向对得上（`d.getOpposite()` 是"从外侧往里长"）。

# 范式 5 · 区块运动：moveSection / rotateSection / configureCenterOfRotation / configureStabilization

**什么时候用**：独立区块要"平移"用 `moveSection`；要"转"用 `rotateSection`（并且**必须**先配旋转中心）；要"转但不跟着转（保持直立）"用 `configureStabilization`。

### 5.1 签名

```text
void moveSection(ElementLink<WorldSectionElement>, net.minecraft.world.phys.Vec3, int);
void rotateSection(ElementLink<WorldSectionElement>, double, double, double, int);
void configureCenterOfRotation(ElementLink<WorldSectionElement>, Vec3);
void configureStabilization(ElementLink<WorldSectionElement>, Vec3);
```

### 5.2 平移（duration=0 表示瞬间）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/infrastructure/ponder/scenes/BearingScenes.java:269-274
```

# 范式 12 · ElementLink 与"迟到绑定"

**什么时候用**：一个元素**只有跑到那一帧才知道要放到哪**（例如"物品掉在传送带上"——位置由当时的方块实体决定）。这时 **不能**先 new 再返回，必须：先建一个空 `ElementLink`，把"创建元素"塞进指令队列，元素真正诞生时再 `linkElement` 绑回去。

### 12.2 Create 的标准"迟到绑定"三件套（真实源码）

```java
// ── 原文出处: allapis/Create-mc1.21.1-dev/src/main/java/com/simibubi/create/foundation/ponder/CreateSceneBuilder.java:161-188
		public ElementLink<BeltItemElement> createItemOnBelt(BlockPos beltLocation, Direction insertionSide,
															 ItemStack stack) {
			ElementLink<BeltItemElement> link = new ElementLinkImpl<>(BeltItemElement.class);
			addInstruction(scene -> {
				PonderLevel world = scene.getWorld();
				BlockEntity blockEntity = world.getBlockEntity(beltLocation);
				if (!(blockEntity instanceof BeltBlockEntity beltBlockEntity))
					return;

				DirectBeltInputBehaviour behaviour = beltBlockEntity.getBehaviour(DirectBeltInputBehaviour.TYPE);
				behaviour.handleInsertion(stack, insertionSide.getOpposite(), false);

				BeltBlockEntity controllerBE = beltBlockEntity.getControllerBE();
				if (controllerBE != null)
					controllerBE.tick();

				com.simibubi.create.content.kinetics.belt.behaviour.TransportedItemStackHandlerBehaviour transporter =
					beltBlockEntity.getBehaviour(com.simibubi.create.content.kinetics.belt.behaviour.TransportedItemStackHandlerBehaviour.TYPE);
				transporter.handleProcessingOnAllItems(tis -> {
					BeltItemElement tracker = new BeltItemElement(tis);
					scene.addElement(tracker);
					scene.linkElement(tracker, link);
					return com.simibubi.create.content.kinetics.belt.behaviour.TransportedItemStackHandlerBehaviour.TransportedResult.doNothing();
				});
			});
			flapFunnel(beltLocation.above(), true);
			return link;
		}
```

逐行解读：
1. 163 行：**先建空 link**（此时场景里还没有任何元素）；
2. 164-185 行：整段塞进 `addInstruction(scene -> {...})`，**推迟到这一帧才执行**；
3. 179-184 行：遍历传送带上的物品，每个 `new BeltItemElement(tis)` → `scene.addElement(tracker)` → **`scene.linkElement(tracker, link)`** 完成绑定；
4. 187 行：把 link 还给调用者，调用者可以立刻写 `scene.world().moveSection(link, ...)` 而不用等元素存在。
