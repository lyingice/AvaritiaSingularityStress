## 协作硬规矩（不是坑，是偏好）

- 视觉叠层 / Mixin / 方块替换三条路，**先讲清代价再选**，不闷头实现。
- 能用原版方块状态表达的，就不要"自建 BE 布尔 + Flywheel 叠层"（同步与重建时机最容易断）。
- 机壳方块是**独立的 `CasingBlock`**，靠 `EncasingRegistry` 配对才能封装，不是"拿别的方块当外壳"。
- 每次改动都要 `./gradlew compileJava --offline`；渲染类改动还要起客户端看日志（无 `CrashReport` / `Missing model` / `MixinApplyError` 才算过），并按 create 模式铁律 3 截图取证。
